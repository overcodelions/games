# codelions games lab

The site at [games.overcodelions.com](https://games.overcodelions.com/): Crater, Puttnik and Glidegang, three iPhone games built with [overcli](https://overcodelions.com/overcli/).

Plain static HTML served by GitHub Pages. The pages are generated by `tools/build_lab.py`; edit it and run `python3 tools/build_lab.py` to rebuild, then commit the HTML.
